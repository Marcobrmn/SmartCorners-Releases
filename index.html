SmartCorners

A free macOS menu bar app that turns screen corners into shortcuts. Open websites or apps, run Shortcuts, capture screenshots, and create a new Calendar event or Notes note.

Try corner detection in Welcome: move the pointer to the top-right corner and look for the green checkmark. The test runs no assigned action.

Create profiles, adjust activation delay and cooldown, choose corner animations and pause from the menu bar.

SmartCorners 0.1.2 — Build 18
Apple Silicon (M1 or later), macOS 13 or later. English interface.

Download SmartCorners

I liked using macOS Hot Corners, but the built-in actions and settings were too limited for what I wanted to do. So I built SmartCorners: I can choose what each corner does and adjust how it responds, without paying for another utility.

This build is not signed with an Apple Developer ID and is not notarized. Follow the installation guide if macOS blocks opening it.
