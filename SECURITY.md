# Security policy

Use the current release, **SmartCorners 0.1.1 — Build 17**.

## Reporting a vulnerability

Do not post exploit details, credentials or personal data in public issues. Use **Security → Report a vulnerability** if that option is available. Otherwise, open an issue requesting a private security contact without including sensitive details.

A private report should include the SmartCorners version, macOS version, reproduction steps and impact. Share only the information needed to investigate.

The in-app report function opens a public GitHub issue draft; it is not a private security channel.

## Download security

SmartCorners is not signed with an Apple Developer ID and is not notarized. Only install it if you trust the source. See the [installation guide](README.md#installation) and [download checksum](SHA256SUMS.txt).
