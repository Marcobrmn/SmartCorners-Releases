# SmartCorners 0.1.0 — Build 10

Apple Silicon (M1 or later) · macOS 13 or later · English interface

## Features

- Assign website, application, Shortcut, screenshot, Calendar and Notes actions to screen corners.
- Create profiles, adjust delay and cooldown, and choose visual feedback.
- Pause and resume monitoring from the menu bar.
- Open a GitHub bug or feature-request draft from the app, or copy the report for manual pasting.

## Installation

Open the DMG in Finder and drag SmartCorners into Applications. Quit any older copy before replacing it.

This build is **not signed with an Apple Developer ID and is not notarized**. If macOS blocks opening, use **System Settings → Privacy & Security → Open Anyway** when offered, and confirm only if you trust the source. See [Apple’s instructions](https://support.apple.com/en-us/102445).

## Known limitations

- Focus mode is not available.
- Calendar and Notes actions open blank items without predefined text.
- Checking for updates closes Settings; the menu bar app keeps running.
- This release is a manual download.

Version 0.1.1 is available with smoother Settings scrolling and an updated action helper. See [release notes](RELEASE_NOTES_0.1.1.md).
