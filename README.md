# SmartCorners — downloads and updates

SmartCorners is a macOS menu bar utility for assigning actions to the four screen corners. It supports profiles, a configurable activation delay and cooldown, and actions such as opening websites, launching apps, running Shortcuts, taking screenshots, and opening a new Calendar event or Note.

**Release status:** No public download is available yet. The first DMG will appear in [Releases](https://github.com/Marcobrmn/SmartCorners-Releases/releases) only after the app, signature, notarization, and installation have been verified on macOS. Do not use old development builds as release candidates.

This repository contains **distribution information**, not the application's source code. It hosts the [Sparkle update feed](appcast.xml), [release notes](RELEASE_NOTES.md), and [privacy notice](PRIVACY.md). The source repository is private. No app source code or signing secrets should be committed here.

For questions or bug reports, open an [issue](https://github.com/Marcobrmn/SmartCorners-Releases/issues). Screenshots and system requirements for the first supported build will be added after testing on the final macOS build.
